# Manajemen Produk (React)

Aplikasi web **Manajemen Produk** (CRUD & Pencarian) yang menggunakan **Vite + React** untuk memenuhi **Tugas Pemrograman Web**.

## Fitur

- **Daftar Produk**: Menampilkan daftar produk (ID, nama produk, harga terformat Rupiah) dalam tata letak grid kartu responsif.
- **Pencarian Produk**: Memfilter daftar produk real-time berdasarkan nama produk.
- **Tambah Produk**: Form dengan validasi nama tidak kosong dan harga > 0.
- **Edit Produk**: Form untuk memperbarui nama dan harga produk terpilih.
- **Hapus Produk**: Konfirmasi sebelum menghapus produk dari daftar.
